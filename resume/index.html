安全性、可觀測性與效能

目前任職鈦創軟體，參與富邦人壽行動保全 BFF／MID 專案，負責 Java／Spring Boot 微服務開發、既有功能調整及 TWID、OCR 等外部服務整合。在 TWID Callback API 設計過程中，我針對暴力請求、快取穿透及狀態不同步等風險進行分析，採用 Request 本身可驗證的密鑰機制搭配 Rate Limit，降低驗證流程對快取狀態的依賴，提升對外 API 的安全性與可靠性。這些經驗讓我更關注驗證方式、業務狀態及跨系統相依關係，並將其納入功能設計與異常處理的考量。

在系統可觀測性方面，我運用 Spring AOP、MDC、Kafka、Queue 與 Batch Insert 設計非同步結構化 Log 流程，兼顧 Request 關聯追蹤、錯誤定位與降低同步寫入負擔，也研究跨執行緒 MDC 資訊繼承的策略與限制。同時參與 Redis Sentinel／Cluster 高可用架構驗證，透過 JMeter 模擬壓力與 Failover 情境，觀察節點切換、Client 重新連線及服務可用性，理解分散式系統在異常狀態下的實際行為。

在資料庫與效能分析方面，我曾處理過 Oracle SQL 執行計畫分析索引與查詢問題，並處理 HikariCP Connection Leak、記憶體及系統資源異常。我習慣先蒐集紀錄與監控指標，透過問題重現、壓力測試及執行環境觀察定位瓶頸，再驗證改善效果。分析時也會考量實際使用情境、資料存取方式及服務需求，讓技術調整能回應系統真正面臨的問題，並確認變更對既有功能的影響。
